# E-Commerce REST API Testing Project

## 📌 Project Overview

Manual REST API testing project designed to demonstrate practical API testing skills using Postman.

The project focuses on functional API testing, authentication, CRUD operations, positive and negative scenarios, boundary testing, response validation, request chaining, variables, regression testing, test documentation, and defect reporting.

## 🎯 Project Objective

The objective is to design and execute a structured API test suite for an e-commerce REST API and document the testing activities as a QA engineer would in a real project.
